# Rank 括号颜色与 Title 前缀

更新日期：2026-11-01。

本说明对应 `/rank` 括号配色修复和新增 `/title`，取代早期说明中的“不允许中括号”和“完整称号不能超过 16 字符”的限制。

## 1. 管理权限与显示顺序

两个指令均需要 `h2020.admin` 权限，默认 OP 可以执行，目标玩家必须在线。控制台使用时不加开头的 `/`。

显示顺序为：

```text
Title Rank 玩家名
```

例如：

```text
冠军 [宝宝] Steve
```

title 不会自动添加括号；rank 会保留你输入的一对外层括号，未输入时自动补齐。

title 和 rank 分别保存。修改或清除其中一项不会清除另一项。两者都不会授予 OP。

## 2. `/rank` 用法

```text
/rank <在线玩家> <内置rank或自定义文字> [基础颜色]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| 在线玩家 | 是 | 游戏名，支持 Tab 补全 |
| 内置 rank 或自定义文字 | 是 | 支持中文、空格、内置 rank、自定义颜色代码和一对外层方括号 |
| 基础颜色 | 否 | 如 `aqua`、`gold`、`&b`；未内嵌颜色的文字使用此颜色 |

保留内置 `VIP`、`MVP+`、`ADMIN` 等用法。`NONE` 清除 rank。输入 `[VIP]` 时属于自定义文字，不会被识别为内置 `VIP`。

### 2.1 括号配色规则

1. 不输入括号时，系统补齐一对方括号。
2. 左括号前有颜色代码时，保留该颜色。
3. 左括号前没有颜色代码时，使用称号第一个相邻文字的有效颜色。
4. 右括号前有颜色代码时，保留该颜色；否则继承前一个文字的有效颜色。
5. 文字本身没有颜色时，使用基础颜色；基础颜色也未填写时使用灰色。

输入的括号必须位于文字外层并配对，不接受 `[A][B]` 等多个独立标签或嵌套括号。此类任意标签可以通过 `/title` 设置。

| 指令 | 结果 |
|---|---|
| `/rank Steve &b宝宝` | 自动补齐青色 `[宝宝]`，左括号不再变灰 |
| `/rank Steve [&b宝宝]` | 左右括号都跟随青色文字 |
| `/rank Steve [宝宝] aqua` | 方括号和文字均为青色 |
| `/rank Steve &7[&b宝宝&7]` | 灰色括号、青色文字 |
| `/rank Steve &c[&b宝宝&6]` | 红色左括号、青色文字、金色右括号 |
| `/rank Steve &aAB&bC` | 绿色左括号及 AB，青色 C 及右括号 |
| `/rank Steve NONE` | 移除 rank，保留已有 title |

旧资料中只保存了 `&b宝宝` 对应内部颜色格式的称号，也会按新规则自动补齐同色括号，无需逐个重新设置。

### 2.2 玩家名字颜色

玩家名使用 rank 中占比最高的颜色，统计可见字符并包含括号，忽略空格和颜色代码。并列时取最先出现的颜色。

title 的颜色不参与统计，也不会把粗体等格式传给玩家名。

例如，红色 title 加青色 `[宝宝]` 时，玩家名仍为青色。默认内置 `[YOUTUBE]` 的白色文字最多，玩家名使用白色。

## 3. `/title` 用法

```text
/title <在线玩家> <前缀文字> [基础颜色]
/title <在线玩家> clear
```

| 参数 | 必填 | 说明 |
|---|---|---|
| 在线玩家 | 是 | 游戏名，支持 Tab 补全 |
| 前缀文字 | 是 | 中文、英文、空格、标点、方括号或其他可显示文字；不会额外套括号 |
| 基础颜色 | 否 | Minecraft 颜色名称或 `&` 颜色代码；默认灰色 |
| `clear` | 清除时使用 | 单独作为文字参数时清除 title，保留 rank |

title 不使用预设称号名单。支持内嵌多色代码，以及 `&l` 粗体、`&o` 斜体、`&r` 重置等 Minecraft 格式。拒绝空白内容、纯格式代码、换行及控制字符。

`&` 后面的合法颜色或格式字符会作为代码解析。如果文字需要保留字面量 `&`，输入 `&&`，例如 `R&&D` 显示为 `R&D`。rank 同样支持 `&&`。

| 指令 | 结果 |
|---|---|
| `/title Steve 冠军 gold` | 金色“冠军”显示在 rank 前 |
| `/title Steve &6&l冠军` | 金色粗体“冠军”显示在 rank 前 |
| `/title Steve [&c活动&6冠军]` | 保留输入的方括号和多色文字 |
| `/title Steve Event Winner aqua` | 青色 `Event Winner` |
| `/title Steve R&&D Team white` | 白色 `R&D Team` |
| `/title Steve clear` | 清除 title，保留 rank |

`clear` 为清除操作的保留词；若确实要显示单词 clear，可输入 `/title Steve clear white`。

两个指令均把末尾可识别的颜色参数作为基础颜色。若文字需要以 `Gold` 结尾，请再加一个基础颜色，例如 `/title Steve Team Gold white`。

### 3.1 与 Minecraft 原版 `/title` 的区别

本插件的 `/title` 用于玩家名字前缀。原版同名指令用于屏幕中央标题，两者用途不同。

如果指令名称被其他插件或原版命令占用，使用：

```text
/hypixel2020:title Steve 冠军 gold
```

原版屏幕标题命令仍可通过 `/minecraft:title` 访问。

## 4. 显示范围、长度与存档

- 聊天和服务端 Tab 显示名称保留完整的 title、rank 和玩家名。
- Tab 继续遵循当前世界过滤以及既有玩家可见性规则。
- 大厅资料菜单独立展示 title 和 rank，rank 侧边栏继续只展示 rank。
- 大厅头顶使用原版队伍前缀，协议限制为 16 个 Java 字符，颜色和格式代码也计入。
- 合并后的头顶前缀超限时，从右侧安全缩短，并保留玩家名的 rank 主色，不切断颜色代码或 Unicode 代理对。超长内容可能导致头顶的 rank 部分不完整，但不会改写存档里的完整文字。
- 对局模式仍可能为头顶标识应用队伍规则；这次未替换这些模式的队伍逻辑。

真人资料保存在 `plugins/Hypixel2020/profiles.yml`；本地脚本运行时位于 `run/plugins/Hypixel2020/profiles.yml`。

| 字段 | 内容 |
|---|---|
| `rank` | 内置 rank 或自定义 rank 使用的 NONE |
| `custom-rank-title` | 自定义 rank，包含其括号及内部颜色代码 |
| `rank-color` | rank 基础颜色 |
| `title` | 额外前缀，保留内部颜色和格式代码 |
| `title-color` | title 基础颜色 |

设置后立即请求保存真人资料。Bot 仍遵循原有临时资料规则。
